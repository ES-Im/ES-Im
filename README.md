### 문제의 원인과 구조를 이해하고, 검증하며 더 나은 코드와 설계를 고민하는 백엔드 개발자입니다.

#### 🖥️ 백엔드에서는, 
Java와 Spring Boot, JPA, QueryDSL, MySQL을 중심으로 백엔드 프로젝트를 개발했습니다. Redis 캐싱, Spring Security와 Batch 등을 적용해봤으며, 기존 계층형 3-tier 프로젝트를 8개 도메인으로 분리하고 헥사고날 구조로 리팩토링한 경험이 있습니다.

#### ☁️ 인프라 & 배포에서는,
AWS ECS와 Jenkins를 활용해 CI/CD 파이프라인을 구성하고, Docker 기반으로 배포 환경을 구축했습니다. 민감한 설정은 AWS SSM Parameter Store로 분리했습니다.

#### 📚 기록하는 습관으로는,

문제 해결 과정과 학습 내용을 GitBook에 기록하고 있습니다. 단순히 해결하는 데 그치지 않고, 원인을 확인하고 적용 결과를 검증하는 과정을 중요하게 생각합니다.
